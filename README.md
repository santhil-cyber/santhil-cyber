<td width="50%" valign="top">

### [Answer Point](https://answer-point.com/)

**A decentralized timestamp notary on Ethereum.**

Prove you had a file on a specific date — no uploads, no middlemen, no trust required. Your file never touches a server: a **SHA-256 hash** is computed in the browser via the **Web Crypto API**, then anchored on Ethereum. Once on-chain, the fingerprint can't be altered or backdated.

**So far:**
- **10.32 GB** of data notarized
- **1,847** files timestamped
- **24,519** on-chain block anchors
- **~1.2s** average hash computation
- **99.97%** uptime since launch

Built with `Solidity` `Ethers.js` `React` `Vite` `MetaMask` `Sepolia Testnet`

> Built it because trusting a centralized notary to stamp a PDF never sat right with me.
